# 深藍雙視角倒車模擬器：第一個可操作版本

依據使用者已選定的方案 D 與 design-decisions.json，於 2026-10-27 確認繼續製作。

## 範圍

以桌面瀏覽器及鍵盤操作為主。主畫面為駕駛視角，含中央、左右後視鏡；右上為固定俯瞰圖。所有視角使用同一個 3D 場景和車輛狀態。提供一個垂直倒車入庫場景，目標為 03 號車位。

P/R/N/D 使用 1/2/3/4 或點擊切換；換檔須停止並踩煞車。↑ 油門，↓ 或空白鍵煞車，←/→ 逐步轉動方向盤，放開保持角度，C 輔助回正。D/R 放開煞車後低速蠕行，煞車優先於油門。提供保持煞車按鈕，方便用滑鼠換檔。Esc 暫停；視窗失焦自動暫停並清除按鍵。暫停凍結狀態，恢復時保持煞車以免突然續行。

車輛採低速單軌模型，車身 1.8 × 4.5 m、軸距 2.7 m；各參數為教學示意，不宣稱真車校準。碰撞前停止，記錄接觸次數，可換檔離開障礙。全車進入車位、朝向對齊且停止一秒才顯示完成。顯示車速、檔位、前輪角度、最近障礙距離與預測軌跡。

## 視覺

參照 assets/style-concepts/D-navy-instruments.png。背景 #091827、面板 #0E2235、青藍 #65C8E5、文字 #E6F1F9、警示 #F3B969。Segoe UI / Microsoft JhengHei；數據採等寬數字。主視角佔約 70%，其餘為俯瞰與操控區。以車內輪廓與實際停車場作為視覺主體，避免無關裝飾卡片。3D 車輛先以程式幾何製作，有車窗、輪胎、車燈與陰影；寫實車模與真車參數校準留後續。
