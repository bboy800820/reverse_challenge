# 寫實視覺升級

使用者要求將畫面做成 assets/style-concepts 的寫實風格，沿用已選定的 D 深藍儀表板、雙視角與鍵盤操作。

目前差距是盒狀車模、幾何樹冠、平坦材質、CSS 儀表板和缺少環境反射。本次以真實 3D 模型、掃描紋理、HDR 環境照明及立體駕駛艙改善，而非用靜態圖片替代運動畫面。模擬、碰撞尺寸、五個同步視角及輸入保留。

## 實作選擇

- 延續 Three.js 與 GitHub Pages，採可再散布的公開授權資產，保存來源與署名，所有檔案置於專案 app/public/assets/。
- 使用細緻車模、瀝青／混凝土／草地紋理和日間 HDR。固定同一車身外框，視覺模型依既有尺度適配，不將視覺車款宣稱為已校準實車。
- 駕駛艙以立體儀表台、輪圈、出風口與有紋理的內裝建立，方向盤和數字跟隨真實模擬狀態。
- 手機可使用同一場景，控制高解析度與鏡面成本。非必要背景素材載入失敗提供降級提示；必要素材失敗可重試，並保留可操作的基礎場景。

替代方向：僅改善程序材質最快，但保留方塊造型；使用生成的靜態駕駛艙圖能提高單張畫面的擬真度，但難以一致呈現動態視角。因此選用即時 3D 視覺升級。這是依既有設計與本次明確視覺要求作出的實作選擇。

完成標準：可見曲面車體和反射、自然細節的路面與植被、可辨識立體內裝；鏡面仍為即時畫面；模型外框對齊碰撞；正常與缺少素材情況不造成未處理錯誤；操作回歸及部署檢查通過。寫實程度以實際截圖呈現，不宣稱與概念圖逐像素相同。
