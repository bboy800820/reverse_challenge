# 鍵盤煞車相容性修正

使用者回報 ↓／空白鍵煞車沒有反應。標準 Edge 鍵盤輸入可煞停；重現到只提供 KeyboardEvent.key、code 為空字串或 Unidentified 時，原有程式忽略事件，車速持續在蠕行速度。未取得使用者瀏覽器的原始事件，因此這是已確認的相容性缺陷，而非對使用者環境原因的斷言。

修正控制鍵辨識：保留有效實體鍵碼，缺少鍵碼時改用邏輯按鍵；keydown/keyup 使用一致的輸入來源識別，並在捕獲階段接收控制鍵。保留多個煞車來源的獨立釋放。新增即時踏板「踩下中／保持中／按住減速」及「已煞停」提示，說明放開踏板後 D/R 會恢復蠕行。

驗證先重現再修正：新增鍵盤測試原有邏輯 8 項失敗，真實頁面 key-only 煞車測試無法停車；修正後單元測試 21/21 通過，瀏覽器測試確認 D/R 各種事件均可煞停，放開後恢復蠕行。建置通過。

使用者另要求將專案上傳 bboy800820/reverse_challenge。檢查儲存庫為公開、空白，預設分支 main。本機準備完整來源、測試、概念圖和操作說明；排除 node_modules、dist、環境設定檔與本機第三方技能。
